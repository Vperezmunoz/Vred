------------------------
vrdGaussianSplatMaterial
------------------------

.. py:class:: vrdGaussianSplatMaterial

(Inherits vrdMaterial)

This class is used to handle all Gaussian splat material properties. This material type must be used in combination with     vrdPointCloudNode.

=======
