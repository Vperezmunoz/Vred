------------------
vrdClippingOptions
------------------

.. py:class:: vrdClippingOptions

(Inherits vrdSceneObject)

Configuration options for clipping planes in variant sets.

This class provides a comprehensive interface for configuring clipping plane properties including position, orientation, visual appearance, and rendering behavior. It is used to control how objects are clipped in 3D scenes using planar clipping.
