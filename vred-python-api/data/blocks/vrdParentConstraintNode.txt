vrdParentConstraintNode

.. py:class:: vrdParentConstraintNode

(Inherits vrdConstraintNode)

Parent constraints control constrained nodes by making them behave like children of target nodes. Multiple targets are combined using weighted average calculations.

To obtain the vrdParentConstraintObject and configure how transformations are applied from target nodes to constrained nodes, see vrdConstraintNode::getConstrainedObject(vrdNode).

For managing constraints and code examples see     vrConstraintService.
