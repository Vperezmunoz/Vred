---------------------------
vrdMeasuredCarpaintMaterial
---------------------------

.. py:class:: vrdMeasuredCarpaintMaterial

(Inherits vrdBRDFMaterial)

This class is used to handle all measured carpaint material properties.

Summary
=======

Functions:

    * getExposure() → float
    * getIncandescence() → vrdIncandescence
    * getRefractionIndex() → float
    * getTextureSettings() → vrdTextureSettings

    * setRefractionIndex(value)
