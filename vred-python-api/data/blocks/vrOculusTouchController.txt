.. method:: triggerVibration(frequency, amplitude)

    Triggers a vibration on the controller.

    IMPORTANT: Beginning with VRED 2022.1, OpenVR is used, and the parameters won't have any effect. The function will generate a single haptic pulse regardless of its parameters. The function triggerHapticPulse() can be used as an alternative as it maps directly to the OpenVR API.

    :param frequency: The frequency of the vibration. Supported values are: 0.0 (disabled), 0.5, and 1.0.
    :type frequency: float
    :param amplitude: The amplitude of the vibration. Must be between 0.0 and 1.0.
    :type amplitude: float

.. method:: triggerHapticPulse(axis, duration)

    Triggers a haptic pulse on the controller.

    :param axis: The axis to trigger the pulse on.
    :type axis: unsigned int
    :param duration: The duration of the pulse in microseconds.
    :type duration: unsigned int
