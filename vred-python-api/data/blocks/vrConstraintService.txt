-------------------
vrConstraintService
-------------------

.. py:class:: vrConstraintService

(Inherits vrBaseService)

Constraints control object transformations based on other objects. They create dynamic relationships where target nodes control the transformations of constrained nodes.

Available constraint types: vrdPositionConstraintNode, vrdOrientationConstraintNode, vrdParentConstraintNode and vrdAimConstraintNode. Constraint groups are available for organizing constraints.

See vrdConstraintNode for constraint tree management and settings and see vrdConstraintObject for per-node parameter management.

Basic usage examples:

```

     # Get some nodes from the scene graph
     obj1 = vrNodeService.findNode("Object1")
     obj2 = vrNodeService.findNode("Object2")
     obj3 = vrNodeService.findNode("Object3")

     # Create a position constraint which synchronizes the position of two objects.
     posConstraint = vrConstraintService.createPositionConstraint([obj1], obj2, False)

     # Change the constrained node of the position constraint.
     posConstraint.setConstrainedNode(obj3)

     # Deletes the constraint.
     vrConstraintService.deleteConstraint(posConstraint)

     # Create another position constraint which synchronizes the position of two objects
     # with a third one and keeps the current offsets.
     posConstraint = vrConstraintService.createPositionConstraint([obj1, obj2], obj3, True)

     # Modify the weight of an object.
     posConstraint.setTargetNodeWeight(obj1, 0.5)

     # Create an aim constraint which computes the target orientation by a source position.
     # The up vector is calculated automatically.
     aimConstraint = vrConstraintService.createAimConstraint([obj1], [], obj2)

     # Find constraints for a given constrained node.
     constraints = vrConstraintService.findConstrainedNode(obj2)

     # Set all found constraints inactive
     for constraint in constraints:
         constraint.setActive(False)

     # Access constraint objects for fine-grained control
     constrainedObjects = posConstraint.getConstrainedObjects()
     for constrainedObj in constrainedObjects:
         constrainedObj.setMaintainOffset(True)
         constrainedObj.setTranslationOffset(QVector3D(1.0, 0.0, 0.0))

.. py:method:: vrConstraintService.copiedNodesAvailable()

    Indicates if there are constraints in the internal copy buffer.

    Nodes can be copied with vrConstraintService.copyNodes(nodes).

    :return: True if there are any constraints in the copy buffer, False otherwise.
    :rtype: bool

.. py:method:: vrConstraintService.copyNodes(nodes)

    Add nodes to the internal copy buffer.

    This adds nodes to the internal copy buffer from where they then can be used with pasteNodes(parent). The copy buffer is always cleared first when this function is called. The copied nodes must be in the constraint tree.

    :param nodes: The nodes to be copied
    :type nodes: List[vrdNode]

.. py:method:: vrConstraintService.createAimConstraint(targetNodes={}, upTargetNodes={}, constrainedNode=vrdNode(), parent=vrdNode())

    Creates a new aim constraint node.

    :param targetNodes: The nodes to use as constraint targets.
    :type targetNodes: List[vrdNode]

    :param upTargetNodes: The nodes to use as constraint up vector targets. Use an empty list for auto calculation.
    :type upTargetNodes: List[vrdNode]

    :param constrainedNode: The node to use as the constrained one.
    :type constrainedNode: vrdNode

    :param parent: This node contains the new constraint node as a child.
    :type parent: vrdNode

    :return: The aim constraint node.
    :rtype: vrdAimConstraintNode

.. py:method:: vrConstraintService.createGroup(parent=vrdNode(), name="", forceUniqueName=True)

    :param name: A name for the new node.
    :type name: string

    :param forceUniqueName: Forces the name of the new node to be unique
    :type forceUniqueName: bool

    :return: The new node
    :rtype: vrdNode

.. py:method:: vrConstraintService.cutNodes(nodes)

    Removes the given nodes from constraints and adds them to the internal copy buffer.

    This adds nodes to the internal copy buffer from where they then can be used with pasteNodes(parent). The copy buffer is always cleared first when this function is called. The cut nodes must be in the constraint tree.

    :param nodes: The nodes to be copied
    :type nodes: List[vrdNode]

    :return: True on success, False otherwise.
    :rtype: bool
