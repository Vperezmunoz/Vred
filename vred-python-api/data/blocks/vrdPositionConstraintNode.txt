-------------------------
vrdPositionConstraintNode
-------------------------

.. py:class:: vrdPositionConstraintNode

(Inherits vrdConstraintNode)

Position constraints control constrained node positions by using target node positions. Multiple targets are combined using weighted average calculations.

To obtain the vrdPositionConstraintObject and configure how transformations are applied from target nodes to constrained nodes, see vrdConstraintNode::getConstrainedObject(vrdNode).

For managing constraints and code examples see     vrConstraintService.

Summary
=======

Functions:
    * getMaintainOffset() → bool
    * setMaintainOffset(value)

    :rtype: bool
