.. method:: applyMaterialAssetsByName(path)

    Each material in the scene is replaced by an equally-named material asset that can be found under the specified directory and its sub-directories.

    :param path: The path to the directory containing material assets.
    :type path: string

.. method:: loadMaterialAssetByName(assetName)

    Loads a material asset by its name.

    :param assetName: The name of the material asset.
    :type assetName: string
    :return: The loaded material asset.
    :rtype: vrMaterialPtr

.. method:: loadMaterialAssetByName(assetName, assetPath)
    :no-index:

    Loads a material asset by its name and optionally its path.

    :param assetName: The name of the material asset.
    :type assetName: string
    :param assetPath: The path to the directory containing the material asset.
    :type assetPath: string
    :return: The loaded material asset.
    :rtype: vrMaterialPtr

.. method:: loadMaterialAssetByUUID(assetUUID)

    Searches for a material asset by its UUID and loads it.

    :param assetUUID: The UUID of the material asset.
    :type assetUUID: string
    :return: The loaded material asset.
    :rtype: vrMaterialPtr

.. method:: createMaterialAsset(material, assetManagerDirectory)

    Saves the given material as a new material asset in the specified directory.

    :param material: The material to be saved as an asset.
    :type material: vrMaterialPtr
    :param assetManagerDirectory: Path of a directory in the Asset Manager.
    :type assetManagerDirectory: string
    :return: Success.
    :rtype: bool

.. method:: overwriteMaterialAsset(material)

    Overwrites an existing material asset in the Asset Manager.

    :param material: A material referencing a material asset in the Asset Manager.
    :type material: vrMaterialPtr
    :return: Success.
    :rtype: bool

.. method:: getSelectedAssetDirectory(assetType)

    Returns the path of the currently selected directory in the Asset Manager.

    :param assetType: The type of asset (e.g., VR_ASSET_MATERIAL).
    :type assetType: enumeration
    :return: The path of the selected directory.
    :rtype: string

.. method:: getSelectedMaterialAssetDirectory()

    Deprecated. Use getSelectedAssetDirectory(VR_ASSET_MATERIAL) instead.

    :return: The path of the selected directory.
    :rtype: string
