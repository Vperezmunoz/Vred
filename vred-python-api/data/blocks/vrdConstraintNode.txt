-----------------
vrdConstraintNode
-----------------

.. py:class:: vrdConstraintNode

(Inherits vrdNode)

Base class for constraint nodes in VRED's constraint system. Provides common functionality for managing constraint relationships between scene nodes.

vrdConstraintNode represents constraint tree organization and general constraint settings. These nodes exist in a separate constraint tree that is managed independently from the main scene graph.

Constraints are relationships that automatically control object transformations based on other objects. They create dynamic linkage where changes to target objects automatically affect constrained objects. Common uses include linking object positions, implementing look-at behaviors, and maintaining spatial relationships during animations.

This is the base class for vrdPositionConstraintNode, vrdOrientationConstraintNode, vrdParentConstraintNode, vrdAimConstraintNode Each specialized type handles constraint-specific logic and parameters

For managing constraints and code examples see     vrConstraintService.
