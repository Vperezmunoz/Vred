-----------------
vrPlatformService
-----------------

.. py:class:: vrPlatformService

(Inherits vrBaseService)

Exposes platform and application information like paths, DPI, and icons.

This service provides access to application, platform, path, DPI, and icon/preview sizing values used across the UI and other subsystems.
