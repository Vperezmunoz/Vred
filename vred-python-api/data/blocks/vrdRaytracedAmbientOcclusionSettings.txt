------------------------------------
vrdRaytracedAmbientOcclusionSettings
------------------------------------

.. py:class:: vrdRaytracedAmbientOcclusionSettings

(Inherits vrdObject)

This class configures the Raytraced Ambient Occlusion in Vulkan rendering mode.

Raytraced Ambient Occlusion (RTAO) uses GPU accelerated ray-tracing to compute areas of the image where the diffuse illumination are occluded by other geometry.

This method produces more accurate results than Screen Space Ambient Occlusion (SSAO) as it has access to all the geometry.

RTAO produces a uniform shadowing result. To get raytraced shadows from the environment map use Raytraced Environment Shadows instead.

Because it uses GPU accelerated ray-tracing, it is only available on those graphic cards with ray-tracing support.

Example:

```

     renderSettings = vrRenderSettingsService.getSettings()
     renderSettings.setUseRealtimeEnvironmentShadows(True)
     renderSettings.setRealtimeEnvironmentShadowsMode(vrRenderSettingsTypes.RaytracedAmbientOcclusion)
     renderSettings.getRaytracedAmbientOcclusionSettings().setRaysPerPixel(2)
