.. py:method:: vrdShadowMaterial.setVisibleInScreenSpaceRefractions(value)

    Allows to control if the material is visible in screen space refractions. If turned on, the shadow material will be visible in screen space refractions but transparent objects behind the shadow material might not be sorted correctly. If turned off, the shadow material will not be visible in screen space refractions but transparent objects behind the shadow material will appear in the correct order. Screen space refractions are only supported in Vulkan rendering mode.

    :param value: Visibility of shadow material in screen space refractions.
    :type value: bool
