--------
vrdSheen
--------

.. py:class:: vrdSheen

(Inherits vrdSceneObject)

This class is used for sheen properties.

    :return: Current used value of sheen color.

    Gets the spectrum of the sheen color.

    :return: The current used spectrum for sheen color.

    :param value: New spectrum for sheen color

    :param enabled: True to enable, False to disable
    :type enabled: bool

.. py:method:: vrdSheen.setRoughness(value)

    Controls the variations of the sheen fibers. The higher the value, the more random the micro fibers of the microscopic structure of the surface. The lower the value, the more regular the micro fibers of the microscopic structure of the surface.

    :param value: New value for sheen roughness.
    :type value: float

    Sets the weight of the sheen layer.

    :param value: New value for the weight
    :type value: float
