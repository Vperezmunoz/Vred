MODULE vrScenegraph (legacy v1 API)

------------
vrScenegraph
------------

The vrScenegraph class contains all necessary functions to work in a scenegraph system.
It supports all basic node functions for changing and rearranging the scenegraph structure.

**Deprecated**. Use API v2 vrScenegraphService instead.

.. method:: copyTransformation(source, target)

    Copies the transformation of one node to another. If only source and target node are provided a full copy will be done, otherwise only the chosen attributes will be copied if the target is a standard transform. If the target is a matrix transform, the full matrix will always be copied.

    :param source: The source node.
    :type source: NodePtr
    :param target: The target node.
    :type target: NodePtr
