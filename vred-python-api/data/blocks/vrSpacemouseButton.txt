.. class:: vrSpacemouseButton(button)

    The spacemouse button class is responsible to trigger functionality when a spacemouse button is pressed. To use it just create a spacemouse button object and connect the callback functionality you need.

    :param button: The spacemouse button. Valid buttons are: "Key_Spacemouse_1" - "Key_Spacemouse_32".
    :type button: unsigned integer

.. function:: setSpacemouseButtonText(index, text)

    Sets the text for the 3Dconnection space pilot button.

    :param index: The index of the button.
    :type index: integer

    :param text: The text of the button to be displayed.
    :type text: string

.. function:: setSpacemouseMenuText(text)

    Sets the text for the 3Dconnection space pilot menu.

    :param text: The text of the menu to be displayed.
    :type text: string
