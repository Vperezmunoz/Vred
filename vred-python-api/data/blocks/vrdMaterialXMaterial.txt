--------------------
vrdMaterialXMaterial
--------------------

.. py:class:: vrdMaterialXMaterial

(Inherits vrdBRDFMaterial)

This class is used to handle all MaterialX based material properties.

    .. py:class:: CompilationType

        Defines the method used to compile the material for Raytracing.

            .. py:data:: InstanceCompilation

                The material is compiled and optimized specifically for its current attribute values. Any MaterialX attribute change (e.g. color) triggers a recompile. Initial material compilation is usually faster with InstanceCompilation than with ClassCompilation.

            .. py:data:: ClassCompilation

                The material is compiled with its attributes as runtime parameters. Changing MaterialX attributes (e.g. colors) does not trigger a recompile, making interactive editing faster at the cost of lower render performance. Initial material compilation usually takes longer with ClassCompilation than with InstanceCompilation.

.. py:method:: vrdMaterialXMaterial.setUseCutoutTransparency(value)

    Enables cutout transparency for the material.

    Useful for rendering materials with opacity masks, such as foliage or grates.

    When enabled, transparency is handled in a binary way: opacity values less than or equal to 0.5 are treated as fully transparent, while values above 0.5 are treated as opaque.

    Cutout enables the opaque parts of the material to cast shadows in the rasterizer. It also allows proper sorting in OpenGL in 'Object Sorting' transparency mode, and can improve raytracing performance when rendering foliage or similar scenes.

    This option does not affect glass-like transmission behavior.

    :param value: New state.
    :type value: bool

.. py:method:: vrdMaterialXMaterial.setUseScreenSpaceRefractions(value)

    :param value: New state.
    :type value: bool
