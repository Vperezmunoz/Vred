--------------------
vrdPhysicsObjectNode
--------------------

.. py:class:: vrdPhysicsObjectNode

(Inherits vrdNode)

The     vrdPhysicsObjectNode class represents a physics object in the scene.

This class provides access to a physics object node that can participate in physics simulation. Physics objects can be configured as static, dynamic, or kinematic colliders, each with different behaviors and properties. Static objects remain fixed in place, dynamic objects are affected by forces and collisions, and kinematic objects can be moved programmatically but are not affected by forces.

    :type density: float

.. py:method:: vrdPhysicsObjectNode.setForce(force)

    Set the force vector to apply to the physics object.

    The force is always specified in Newtons (N) regardless of scene unit mode, and is automatically converted to scene units internally. The actual units depend on the force mode:

    Force: Newtons (N) - continuous force affected by massImpulse: Newton-seconds (N·s) - instantaneous impulse affected by mass, auto-disables after applicationVelocity Change: meters/second (m/s) - direct velocity change, mass independentAcceleration: meters/second² (m/s²) - direct acceleration, mass independent

    :param force: The force vector. Always specified in Newtons.
    :type force: QVector3D

.. py:method:: vrdPhysicsObjectNode.setForceEnabled(enabled)

    Enable or disable continuous force application.

    When enabled, the force and torque vectors are applied every frame according to the selected force mode. When disabled, no forces are applied.

    :param enabled: True to enable force application, false to disable.
    :type enabled: bool

.. py:method:: vrdPhysicsObjectNode.setForceMode(mode)

    Set the force application mode.

    The force mode determines how forces and torques are applied:

    Force: Continuous force affected by mass/inertia (N, N·m) - applied every frame while enabledImpulse: Instantaneous impulse affected by mass/inertia (N·s, N·m·s) - applied once then auto-disablesVelocity Change: Direct velocity change ignoring mass/inertia (m/s, rad/s) - applied every frame while enabledAcceleration: Direct acceleration ignoring mass/inertia (m/s², rad/s²) - applied every frame while enabled

    :param mode: The desired force application mode.
    :type mode: vrPhysicsTypes.ForceMode

    :type worldFrame: bool

.. py:method:: vrdPhysicsObjectNode.setSleepThreshold(sleepThreshold)

    Set the motion threshold below which objects go to sleep.

    When an object's motion falls below this threshold, it is put to sleep to improve performance. Sleeping objects are not simulated until woken by a collision or force.

    :param sleepThreshold: The motion threshold in m/s². Must be >= 0.0.
    :type sleepThreshold: float

    :type enabled: bool

.. py:method:: vrdPhysicsObjectNode.setTorque(torque)
