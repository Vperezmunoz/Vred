-------------------
vrdPhysicsGroupNode
-------------------

.. py:class:: vrdPhysicsGroupNode

(Inherits vrdNode)

The     vrdPhysicsGroupNode class represents a physics group in the scene.

Physics groups are used to organize physics objects and provide a way to activate or deactivate multiple physics objects together. Groups can contain physics objects and other physics groups, creating a hierarchical structure.

Groups can be activated or deactivated, which affects all physics objects within the group. When a group is inactive, all physics objects within it are also inactive.

.. py:method:: vrdPhysicsGroupNode.setActive(active)

    Activate or deactivate the physics group.

    When a group is deactivated, all physics objects within it are also deactivated. When activated, physics objects within the group respect their individual active states.

    :param active: True to activate the group, false to deactivate it.
    :type active: bool
