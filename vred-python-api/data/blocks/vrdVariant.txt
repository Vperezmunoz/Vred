----------
vrdVariant
----------

.. py:class:: vrdVariant

(Inherits vrdSceneObject)

Provides a mechanism to target and change scene objects.

A variant targets one or more objects in the scene. The target objects are resolved based on the properties searchMethod and targetType. The search method defines how the target objects are found (e.g. by name). The target type acts as a filter on the found objects and restricts them to a specific type (see vrVariantTypes.TargetType).

A variant can change its target objects by executing a state on it. Depending on the target(s), different states are available. For example, a variant targeting a node can have a state for setting its visibility on or off, while a variant targeting a material switch can have states for selecting different sub-materials.

Also, there are a number of built-in states that are available through vrVariantStates. Some of them are special control states that allow for more complex interactions (e.g. cycling through the available states).

    :return: A list with states that can be executed on this variant.
    :rtype: List[string]

.. py:method:: vrdVariant.getCurrentState()

    Gets the state of every target object.

    :return: The current state of the target objects.
    :rtype: List[string]

.. py:method:: vrdVariant.getDefaultState()

    Gets the default state of this variant.

    Normally, the default state will be the state the first target object is currently in. In case its current state is empty, the default state will be one of the available states that can be set on the targets.

    :return: The default state.
    :rtype: string
