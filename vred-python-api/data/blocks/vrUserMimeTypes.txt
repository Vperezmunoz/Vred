---------------
vrUserMimeTypes
---------------

.. py:class:: vrUserMimeTypes

Contains constants for all user accessible MIME types. Provides methods for extracting and interpreting their data.

    .. py:class:: DataType

        Type of the MIME data.

            .. py:data:: Invalid

            .. py:data:: String

            .. py:data:: VrdObject

            .. py:data:: Custom
               :no-index:

            .. py:data:: Any

Functions
=========

.. py:method:: vrUserMimeTypes.decode(data, type)

    Decodes arbitrary instances from given MIME data.

    :param data: The MIME data to decode from.
    :type data: QMimeData

    :param type: The MIME type to query.
    :type type: string

    :return: A QVariant holding a list with the decoded instances.
    :rtype: QVariant

.. py:method:: vrUserMimeTypes.decodeObjects(data, type)

    Decodes         vrdObject instances from given MIME data.

    :param data: The MIME data to decode from.
    :type data: QMimeData

    :param type: The MIME type to query.
    :type type: string

    :return: A list with the decoded vrdObject instances.
    :rtype: List[vrdObject]

.. py:method:: vrUserMimeTypes.decodeStrings(data, type)

    Decodes QString instances from given MIME data.

    :param data: The MIME data to decode from.
    :type data: QMimeData

    :param type: The MIME type to query.
    :type type: string

    :return: A list with the decoded QString instances.
    :rtype: List[string]

.. py:method:: vrUserMimeTypes.findType(types, dataType)

    Searches given MIME types for the first type with given data type.

    :param types: The MIME types to be searched.
    :type types: List[string]

    :param dataType: The desired data type.
    :type dataType: DataType

    :return: The first MIME type that has given data type.
    :rtype: string

.. py:method:: vrUserMimeTypes.findTypes(types, dataType)

    Searches given MIME types for all types with given data type.

    :param types: The MIME types to be searched.
    :type types: List[string]

    :param dataType: The desired data type.
    :type dataType: DataType

    :return: The MIME types that have given data type.
    :rtype: List[string]

.. py:method:: vrUserMimeTypes.getDataType(type)

    Gets the data type of a MIME type.

    :param type: The MIME type to query.
    :type type: string

    :return: The data type of the given MIME type.
    :rtype: DataType

.. py:method:: vrUserMimeTypes.getTypes(dataType=DataType.Any)

    Gets the MIME types which have the given data type.

    :param dataType: The data type to query.
    :type dataType: DataType

    :return: A list with the MIME type strings.
    :rtype: List[string]

.. py:method:: vrUserMimeTypes.hasDataType(type, dataType)

    Tells if the given MIME type has given data type.

    :param type: The MIME type to query.
    :type type: string

    :param dataType: The data type to query.
    :type dataType: DataType

    :return: True, if the MIME type has given data type.
    :rtype: bool
