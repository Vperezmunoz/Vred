------------
vrdShadowMap
------------

.. py:class:: vrdShadowMap

(Inherits vrdSceneObject)

This class gives access to settings of shadow maps in OpenGL and Vulkan rendering.

Summary
=======

    * getResolution() → integer
    * setFilterRadius(radius)
    * setResolution(resolution)
