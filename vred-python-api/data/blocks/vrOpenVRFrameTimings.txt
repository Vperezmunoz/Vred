MODULE vrOpenVRFrameTimings (legacy v1 API)

---------------------
vrOpenVRFrameTimings
---------------------

The `vrOpenVRFrameTimings` class stores timing information from the OpenVR library that can be queried by calling `getOpenVRFrameTimings()`. The timing information always refers to the last rendered frame.

    Returns the index of the current frame.

    :return: The current frame id.
    :rtype: UInt32

    :return: The current frame index.
    :rtype: UInt32

.. method:: getNumFramePresents()

    Returns the number of times this frame was presented.

    :return: The number of times this frame was presented.
    :rtype: UInt32

.. method:: getNumMisPresented()

    Returns the number of times this frame was presented on a vsync other than it was originally predicted to.

    :return: The number of times this frame was mispresented.
    :rtype: UInt32

.. method:: getNumDroppedFrames()

    Returns the number of additional times the previous frame was scanned out.

    :return: The number of additional times the previous frame was scanned out.
    :rtype: UInt32

.. method:: getReprojectionFlag()

    Returns whether the frame was reprojected or not.

    :return: The reprojection state.
    :rtype: UInt32

.. method:: getSystemTimeInSeconds()

    Returns the absolute time reference for comparing frames. This aligns with the vsync that running start is relative to.

    :return: The absolute system time reference in seconds.
    :rtype: Real64

.. method:: getPreSubmitGpu()

    Returns the time spent rendering the scene.

    :return: The time spent rendering the scene in milliseconds.
    :rtype: Real32

.. method:: getPostSubmitGpu()

    Returns the additional time spent rendering by the application (e.g., companion window).

    :return: The additional rendering time in milliseconds.
    :rtype: Real32

.. method:: getTotalRenderGpu()

    Returns the time between work submitted immediately after present (ideally vsync) until the end of compositor-submitted work.

    :return: The total GPU render time in milliseconds.
    :rtype: Real32

.. method:: getCompositorRenderGpu()

    Returns the time spent performing distortion correction, rendering chaperone, overlays, etc.

    :return: The compositor rendering time in milliseconds.
    :rtype: Real32

.. method:: getCompositorRenderCpu()

    Returns the time spent on the CPU submitting the above work for this frame.

    :return: The time spent on the CPU in milliseconds.
    :rtype: Real32

.. method:: getCompositorIdleCpu()

    Returns the time spent waiting for running start (application could have used this much more time).

    :return: The time spent waiting for running start in milliseconds.
    :rtype: Real32

.. method:: getClientFrameInterval()

    Returns the time between calls to WaitGetPoses.

    :return: The time between calls to WaitGetPoses in milliseconds.
    :rtype: Real32

.. method:: getPresentCallCpu()

    Returns the time blocked on the call to present (usually 0.0, but can go long).

    :return: The present call time in milliseconds.
    :rtype: Real32

.. method:: getWaitForPresentCpu()

    Returns the time spent spin-waiting for the frame index to change (not near-zero indicates wait object failure).

    :return: The time waiting for the next frame in milliseconds.
    :rtype: Real32

.. method:: getSubmitFrameTime()

    :return: The time spent submitting the current frame in milliseconds.
