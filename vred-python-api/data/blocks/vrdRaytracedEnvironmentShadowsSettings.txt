--------------------------------------
vrdRaytracedEnvironmentShadowsSettings
--------------------------------------

.. py:class:: vrdRaytracedEnvironmentShadowsSettings

(Inherits vrdObject)

This class configures the Raytraced Environment Shadows in Vulkan rendering mode.

Raytraced Environment Shadows uses GPU accelerated ray-tracing to compute the shadows from the environment map.

It is similar to Raytraced Ambient Occlusion (RTAO), but it takes into consideration the bright areas of the environment map, producing a result that is biased towards those directions, while the RTAO produces a more uniform result.

Because it uses GPU accelerated ray-tracing, it is only available on those graphic cards with ray-tracing support.

Example:

```

     renderSettings = vrRenderSettingsService.getSettings()
     renderSettings.setUseRealtimeEnvironmentShadows(True)
     renderSettings.setRealtimeEnvironmentShadowsMode(vrRenderSettingsTypes.RaytracedEnvironmentShadows)
     renderSettings.getRaytracedEnvironmentShadowSettings().setRaysPerPixel(2)
