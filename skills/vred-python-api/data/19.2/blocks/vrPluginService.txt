---------------
vrPluginService
---------------

.. py:class:: vrPluginService

(Inherits vrBaseService)

Interface to manage plugins in VRED.

This service provides functions to manage plugins in VRED, including reloading script plugins and retrieving a list of available script plugins.

Summary
=======

Functions:
    * getScriptPluginInfo(name) → vrdScriptPluginInfo
    * getScriptPluginInfos() → List[vrdScriptPluginInfo]
    * getScriptPluginNames() → List[string]
    * reloadScriptPlugins()
