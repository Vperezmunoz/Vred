-----------------
vrdVariantSetNode
-----------------

.. py:class:: vrdVariantSetNode

(Inherits vrdNode)

Node containing a variant set.

These nodes are part of the variant set tree. Its root can be obtained by calling     vrVariantService.getVariantSetRoot().
