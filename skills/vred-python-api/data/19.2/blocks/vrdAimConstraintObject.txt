----------------------
vrdAimConstraintObject
----------------------

.. py:class:: vrdAimConstraintObject

(Inherits vrdConstrainedObject)

This constraint object represents constrained nodes in aim constraints (    vrdAimConstraintNode). It defines how target node transformations control the constrained node's rotation to make it look toward the targets. To obtain this object, see vrdConstraintNode::getConstrainedObject(vrdNode).
