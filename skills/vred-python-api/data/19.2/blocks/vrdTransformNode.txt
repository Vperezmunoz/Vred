----------------
vrdTransformNode
----------------

.. py:class:: vrdTransformNode

(Inherits vrdNode)

Transformation node.

Euler angles are given in degrees. The world transformation functions transform the world space value into the coordinate system of the given node. World transformations of clones of this node are not taken into account for this calculation.

Translation methods: setTranslation sets the node's translation component directly. setWorldTranslation applies a world-space translation. Its result differs from setTranslation when any parent nodes are transformed. setLocalTranslation moves along the node's local axes. Its result differs from setTranslation when this node has a rotation or a pivot orientation.

.. py:method:: vrdTransformNode.addLocalTranslation(localTranslationDelta)

    Adds a translation delta along the node's local axes, as when using the translation manipulator in "Local Mode".

    Prefer to use this helper to apply movements along local axes. It should give more stable results than using getLocalTranslation/setLocalTranslation repeatedly.

    Example usage:

```

         # Move node by 100 units along its local Z axis
         node.addLocalTranslation(QVector3D(0, 0, 100))

    For reference, a manual implementation of the snippet above would be:

```

         qr = node.getRotationAsQuaternion()
         qro = node.getRotationOrientationAsQuaternion()
         t = node.getTranslation()
         tlocal = QVector3D(0, 0, 100) # movement vector along local axes
         tdelta = (qr * qro).rotatedVector( tlocal) # rotate to node coordinate system
         node.setTranslation( t + tdelta)

    :param localTranslationDelta: Vector along local axes
    :type localTranslationDelta: QVector3D

.. py:method:: vrdTransformNode.setRotationOrientationAsDirection(direction)

    Sets the rotation pivot orientation from a direction vector and axis, such that the selected pivot's axis is aligned with the direction vector.

    For example, to change the pivot orientation such that the pivot's Z axis is aligned with the object space vector (1, 1, 1):

```

         node.setRotationOrientationAsDirection((QVector3D(1, 1, 1), vrTransformTypes.Axis.Z))

    :param direction: Vector: Direction vector in object space coordinates. Does not need to be normalized. Axis: Pivot axis that is aligned with the direction vector.
    :type direction: Tuple[QVector3D, vrTransformTypes.Axis]
