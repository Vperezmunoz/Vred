---------------------------
vrdPositionConstraintObject
---------------------------

.. py:class:: vrdPositionConstraintObject

(Inherits vrdConstrainedObject)

This constraint object represents constrained nodes in position constraints (    vrdPositionConstraintNode). It defines how target node positions control the constrained node's location through translation and offset parameters. To obtain this object, see vrdConstraintNode::getConstrainedObject(vrdNode).
