MODULE vrAnimWidgets (legacy v1 API)

-------------
vrAnimWidgets
-------------

Contains functionality for managing animation widgets, including keyframes, animation blocks, and clips.

.. class:: vrAnimWidgets

   Provides methods to interact with animation widgets in VRED.

.. method:: playAnim(name, startFrame=None, endFrame=None)

    Plays an animation block or animation clip from start to end via name. The function waits till animation is finished.

    :param name: name of the animation object.
    :type name: string
    :param startFrame: the optional start of the play range
    :type startFrame: float
    :param endFrame: the optional end of the pay range
    :type endFrame: float

.. method:: stopAnim(name)

    Stops the animation evaluation of an animation block or clip.

    :param name: The name of the animation object.
    :type name: string

.. method:: resetAnim(name)

    Resets the animation block or clip.

    :param name: The name of the animation object.
    :type name: string

.. method:: playCAnimation(name, startFrame=None, endFrame=None)

    Plays an animation block or animation clip from start to end via name. This function returns immediatly.

    :param name: name of the animation object
    :type name: string
    :param startFrame:  the optional start of the play range
    :type startFrame: float
    :param endFrame: the optional end of the pay range
    :type endFrame: float

.. method:: pauseCAnimation(name, value)

    Pauses or resumes an animation block or clip.

    :param name: The name of the animation object.
    :type name: string
    :param value: True to pause, False to resume.
    :type value: bool

.. method:: resetCAnimation(name)

    Resets the animation block or clip.

    :param name: The name of the animation object.
    :type name: string
