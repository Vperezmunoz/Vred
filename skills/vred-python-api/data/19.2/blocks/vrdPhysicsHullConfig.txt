.. py:method:: vrdPhysicsHullConfig.setMergeGeometries(enable)

    Set whether to merge geometries before creating hulls.

    If this is enabled, all child geometries of the node will be merged into a single geometry before creating the hull. Otherwise a separate convex hull will be created for each child geometry.

    The default value is 'true'.

    :param enable: True to merge geometries, False otherwise.
    :type enable: bool

.. py:method:: vrdPhysicsHullConfig.setUseBoundingBox(enable)

    Set whether to use the bounding box of the geometry to create the convex hull.

    This is an optimization that can be used to speed up the creation of convex hulls. If precise hulls are not required, this can be enabled to create a convex hull that matches an object oriented bounding box of the geometry. This can be used as a replacement for the normal PhysX box collider since it also works with geometies that are mirrored with a negative scaling factor. This has no effect on convex decomposition.

    The default value is 'false'.

    :param enable: True to use the bounding box, False otherwise.
    :type enable: bool
