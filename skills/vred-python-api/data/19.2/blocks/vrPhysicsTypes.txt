    .. py:class:: ForceMode

        The ForceMode enum defines how forces and torques are applied to physics objects. Corresponds to PhysX PxForceMode enum.

        Important behavioral notes:

        Force: Requires eRETAIN_ACCELERATIONS flag to work properly (auto-enabled when used)Impulse: Applied once, then forceEnabled is automatically disabled to prevent accumulationVelocityChange: Applied continuously each frame, ignoring massAcceleration: Applied continuously each frame, ignoring mass
