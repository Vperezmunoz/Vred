    .. py:class:: MergeOptions

        Defines options for merging materials.

            .. py:data:: Default
               :no-index:

                Default: compare name and skip Switch materials and merge all other material types including X-Rite. Compare all properties including inactive properties.

            .. py:data:: IgnoreName

                Do not compare the name of the material, i.e., materials with different names can be merged. NOTE: Merging materials with different names might break existing variant sets with material variants, as these are name-based.

            .. py:data:: IncludeSwitchMaterials

                Also merge Switch materials. When not setting this option, switch materials are excluded from the merge operation.

            .. py:data:: ExcludeXRiteMaterials

                Do not merge X-Rite materials. When setting this option, X-Rite materials are excluded from the merge operation.

            .. py:data:: IgnoreInactiveProperties

                Do not compare inactive properties of the material, i.e. materials with different inactive properties can be merged. Inactive properties are settings for features that are turned off in the material, e.g. clearcoat properties when the clearcoat is disabled, or texture settings when the texture is disabled or no image is loaded for it. By default all properties including inactive properties are compared.
