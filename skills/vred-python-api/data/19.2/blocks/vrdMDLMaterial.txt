--------------
vrdMDLMaterial
--------------

.. py:class:: vrdMDLMaterial

(Inherits vrdBRDFMaterial)

This class is used to handle all MDL module based material properties.

An MDL material represents a module and can contain multiple materials.

    .. py:class:: CompilationType
       :no-index:

        Defines the method used to compile the material for Raytracing.

            .. py:data:: InstanceCompilation
               :no-index:

                The material is compiled and optimized specifically for its current attribute values. Any MDL attribute change (e.g. color) triggers a recompile. Initial material compilation is usually faster with InstanceCompilation than with ClassCompilation.

            .. py:data:: ClassCompilation
               :no-index:

                The material is compiled with its attributes as runtime parameters. Changing MDL attributes (e.g. colors) does not trigger a recompile, making interactive editing faster at the cost of lower render performance. Initial material compilation usually takes longer with ClassCompilation than with InstanceCompilation.

.. py:method:: vrdMDLMaterial.setUseCutoutTransparency(value)

    Enables cutout transparency for the material.

    Useful for rendering materials with opacity masks, such as foliage or grates.

    When enabled, transparency is handled in a binary way: opacity values less than or equal to 0.5 are treated as fully transparent, while values above 0.5 are treated as opaque.

    Cutout enables the opaque parts of the material to cast shadows in the rasterizer. It also allows proper sorting in OpenGL in 'Object Sorting' transparency mode, and can improve raytracing performance when rendering foliage or similar scenes.

    This option does not affect glass-like transmission behavior.

    :param value: New state.
    :type value: bool

.. py:method:: vrdMDLMaterial.setUseScreenSpaceRefractions(value)

    Enable or disable the use of screen space refractions (only supported in Vulkan rendering mode).

    :param value: New state.
    :type value: bool
