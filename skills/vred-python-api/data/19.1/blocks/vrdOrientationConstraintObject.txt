------------------------------
vrdOrientationConstraintObject
------------------------------

.. py:class:: vrdOrientationConstraintObject

(Inherits vrdConstrainedObject)

This constraint object represents constrained nodes in orientation constraints (    vrdOrientationConstraintNode). It defines how target node rotations control the constrained node's orientation through rotation and offset parameters. To obtain this object, see vrdConstraintNode::getConstrainedObject(vrdNode).

.. py:method:: vrdOrientationConstraintObject.getEulerRotationOffset()

    Returns the euler rotation offset applied to the constraint result. Only applied when maintain offset is disabled.

    :return: The rotation offset in euler angles (degrees).
    :rtype: QVector3D

.. py:method:: vrdOrientationConstraintObject.getMaintainOffset()

    Returns whether the current offset is maintained.

    :return: True if offset is maintained, False otherwise.
    :rtype: bool

.. py:method:: vrdOrientationConstraintObject.getScalingFactor()

    Returns the scaling factors applied to the constraint computation.

    :return: The scaling factors for X, Y, Z axes.
    :rtype: QVector3D

.. py:method:: vrdOrientationConstraintObject.getUseWorldSpaceConstrainedSystem()

    Returns whether world space coordinate system is used for constrained nodes.

    :return: True if world space is used, False if local space is used.
    :rtype: bool

.. py:method:: vrdOrientationConstraintObject.getUseWorldSpaceTargetSystem()

    Returns whether world space coordinate system is used for target nodes.

    :return: True if world space is used, False if local space is used.
    :rtype: bool

.. py:method:: vrdOrientationConstraintObject.setEulerRotationOffset(eulerRotation)

    Sets additional euler rotation offset applied to the constraint result. Only applied when maintain offset is disabled.

    :param eulerRotation: The rotation offset in euler angles (degrees).
    :type eulerRotation: QVector3D

.. py:method:: vrdOrientationConstraintObject.setMaintainOffset(maintain)

    Sets whether to maintain the current offset when applying the constraint.

    :param maintain: True to maintain offset, False to ignore current offset.
    :type maintain: bool

.. py:method:: vrdOrientationConstraintObject.setScalingFactor(scalingFactor)

    Sets scaling factors applied to the constraint computation.

    :param scalingFactor: The scaling factors for X, Y, Z axes.
    :type scalingFactor: QVector3D

    Sets whether to use world space coordinate system for constrained nodes.

    :type use: bool

.. py:method:: vrdOrientationConstraintObject.setUseWorldSpaceTargetSystem(use)

    Sets whether to use world space coordinate system for target nodes.
