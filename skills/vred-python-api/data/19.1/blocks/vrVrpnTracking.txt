.. class:: vrTrackerSensor(name, type)

    The vrTrackerSensor class is the base class for all sensors like bodies, buttons, and dials. You can only access sensors that are already created in the tracking module, meaning you cannot create new sensors with the Python API. All objects constructed with the Python API work as proxy objects to access the VRED internal tracking sensors.

    This class is only a base class and should not be instantiated directly. Use vrTrackerButton, vrTrackerDial, vrTrackerAnalog, or vrTrackerBody instead.

    :param name: The name of the sensor.
    :type name: string
    :param type: The type of the sensor.
    :type type: string

.. method:: setSensorId(id)

    Sets a specific sensor ID to the sensor. This is used for further identification.

    :param id: The ID of the sensor.
    :type id: int

.. method:: setEnabled(state)
    :no-index:

    Enables the sensor.

    :param state: Sensor state: On/Off.
    :type state: bool

.. method:: getType()
    :no-index:

    Returns the type of this sensor. Possible types are "Body", "Dial", "Button", and "Analog".

    :return: The type of the sensor.
    :rtype: string

.. method:: getName()
    :no-index:

    Returns the name of this sensor.

    :return: The name of the sensor.
    :rtype: string

.. class:: vrTrackerBody(name)

    The vrTrackerBody class is a proxy class to access a tracking body as defined in the Tracking GUI module. To create a vrTrackerBody object for an existing body, pass its name as the only parameter to its constructor. The name is a user-definable string set in the tracking GUI in VRED.

    :param name: The name of the tracking body.
    :type name: string

.. method:: setNode(name)
    :no-index:

    Sets the name of the node connected to this body. The tracking system will update the transformation matrix of the node. Only transform nodes can be attached to a body.

    :param name: The name of the node.
    :type name: string

.. method:: getNode()
    :no-index:

    Returns the name of the node connected to this body.

    :return: The name of the node.
    :rtype: string
