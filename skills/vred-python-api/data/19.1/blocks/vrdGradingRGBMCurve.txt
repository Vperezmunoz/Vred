-------------------
vrdGradingRGBMCurve
-------------------

.. py:class:: vrdGradingRGBMCurve

(Inherits vrdSceneObject)

Class to access grading functionality.

To access the grading of a camera or viewpoint, use vrdCameraBaseNode.getGradingRGBCurve():

```

     cam = vrCameraService.getActiveCamera()
     grading = cam.getGradingRGBCurve()
