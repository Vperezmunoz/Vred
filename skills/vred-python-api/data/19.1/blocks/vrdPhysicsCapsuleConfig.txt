.. py:method:: vrdPhysicsCapsuleConfig.setAxisTranslation(translation)

    Set the axis translation for the capsule.

    :param translation: Translation along the capsule's principal axis Positive values move geometry toward the positive cap, negative toward the negative cap. This allows manual optimization of cap utilization.
    :type translation: float

.. py:method:: vrdPhysicsCapsuleConfig.setCustomPrincipalAxis(axis)

    Set the custom principal axis for the capsule.

    This axis defines the direction of the capsule's main cylinder. Set to (0, 0, 0) to use auto-calculated axis from geometry. Non-zero vectors will be automatically normalized and used as the custom axis. For tire geometries, typically set this to the wheel's rotation axis.

    :param axis: The principal axis direction vector. Use (0, 0, 0) for auto-calculation.
    :type axis: QVector3D

.. py:method:: vrdPhysicsCapsuleConfig.setLengthScale(scale)

    :param scale: The scaling factor for the length. Values > 1.0 increase length, < 1.0 decrease length.
    :type scale: float
