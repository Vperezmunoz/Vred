.. py:method:: vrFileIOService.checkCadType(file)

    Asynchronously starts querying the CAD file type of a file with the given file path. After succesfully querying the type or looking it up in a cache a fileTypeReceived signal is emitted. This might be needed since some file extensions, i.E. .prt, can't be clearly associated with a single file type.

    :param file: The filename of the CAD file
    :type file: string
