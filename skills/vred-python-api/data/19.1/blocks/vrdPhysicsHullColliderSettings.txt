.. py:method:: vrdPhysicsHullColliderSettings.setMergeGeometries(enable)

    Set whether to merge geometries before creating hulls.

    If this is enabled, all child geometries of the node will be merged into a single geometry before creating the hull. Otherwise a separate convex hull will be created for each child geometry.

    The default value is 'true'.

    :param enable: True to merge geometries, False otherwise.
    :type enable: bool

.. py:method:: vrdPhysicsHullColliderSettings.setPreprocessGeometry(enable)

    Set whether to preprocess the geometry before creating the convex hull.

    Preprocessing can improve the quality and performance of convex hull creation by cleaning up the geometry data.

    :param enable: True to preprocess the geometry, False otherwise.
    :type enable: bool

.. py:method:: vrdPhysicsHullColliderSettings.setUseBoundingBox(enable)

    Set whether to use the bounding box of the geometry to create the convex hull.

    This is an optimization that can be used to speed up the creation of convex hulls. If precise hulls are not required, this can be enabled to create a convex hull that matches an object oriented bounding box of the geometry. The default value is 'false'.

    :param enable: True to use the bounding box, False otherwise.
    :type enable: bool
