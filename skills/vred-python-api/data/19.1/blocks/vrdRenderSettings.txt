.. py:method:: vrdRenderSettings.canVariantSetViewpointBeUsed()

    Checks if the viewpoints defined in variant sets can be used. If variant sets are not used, their viewpoints will not be used. If a camera track is used, the camera position is determined by the viewpoints in the camera track, and the viewpoints in the variant sets will be ignored. See also:         vrdRenderSettings.setUseVariantSets(variantSetsUsed), setView(vrdNode) and vrdRenderSettings.isCameraTrackUsed()

    :return: True if the viewpoints of variant sets can be used, false otherwise.
    :rtype: bool

.. py:method:: vrdRenderSettings.getAaThresholdQuality()

    Gets the AA threshold quality. The "Highest Quality" disables adaptive antialiasing and delivers the highest quality but might waste computations of regions of the image that do not need any further processing.

    :return: The AA threshold quality.
    :rtype: vrRenderSettingsTypes.AAthresholdQuality

.. py:method:: vrdRenderSettings.getAllowShaderExecutionReordering()

    Gets whether shader execution reordering is allowed. If enabled, the GPU raytracer is permitted to reorder shader executions to improve performance on supported hardware. This is a hint and may have no effect if the hardware or driver does not support shader execution reordering. This setting only applies to GPU Raytracing.

    :return: True if shader execution reordering is allowed, false otherwise.
    :rtype: bool

    Gets the meta data flags. This feature embeds certain scene settings in the rendered output. Later, you can import the rendering into VRED, using File > Import Scene Data > Rendering Meta Data.
