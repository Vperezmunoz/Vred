----------------------
vrdDisplacementTexture
----------------------

.. py:class:: vrdDisplacementTexture

(Inherits vrdTexture)

This class is used for all displacement texture properties.

To load an image for a displacement texture, use:

```

     image = vrImageService.loadImage(filename, vrImageTypes.LoadType.Displacement)
     # Set as displacement texture for a material
     plastic = vrMaterialService.findMaterial("Plastic")
     plastic.getDisplacementTexture().setImage(image)
     plastic.getDisplacementTexture().setUseTexture(True)
     plastic.getDisplacementTexture().setDisplacementHeight(10.0)

.. py:method:: vrdDisplacementTexture.setDisplacementEdgeLengthVulkan(edgeLength)

    Sets the target edge length in scene units for displacement tessellation in Vulkan.

    Low values will result in a finer surface structure at the price of a lower performance. Triangles will be tessellated until the edge length is reached. The minimum edge length is limited by the maximum tessellation level provided by the GPU.

    :param edgeLength: New value for edge length
    :type edgeLength: float

.. py:method:: vrdDisplacementTexture.setDisplacementHeight(height)

    :type height: float

.. py:method:: vrdDisplacementTexture.setDisplacementOffset(offset)

    Sets the reference value for zero displacement.

    This value controls which texture values cause inward or outward displacement:

    Texture values == offset: no displacement. Texture values < offset: displacement along the negative normal direction (inward). Texture values > offset: displacement along the positive normal direction (outward).

    :param offset: New value for offset
    :type offset: float
