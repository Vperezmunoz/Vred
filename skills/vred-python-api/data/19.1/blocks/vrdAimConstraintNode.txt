--------------------
vrdAimConstraintNode
--------------------

.. py:class:: vrdAimConstraintNode

(Inherits vrdConstraintNode)

Aim constraints control constrained node orientations by using target node positions and optional up vector targets. Multiple targets are combined using weighted average calculations.

To obtain the vrdAimConstraintObject and configure how transformations are applied from target nodes to constrained nodes, see vrdConstraintNode::getConstrainedObject(vrdNode).

For managing constraints and code examples see     vrConstraintService.
