MODULE vrNodePtr (legacy v1 API)

---------
vrNodePtr
---------

.. class:: vrNodePtr

   The NodePtr class is a Python representation of a node within the scenegraph. It can be used to alter the existing structure by adding/removing nodes.

   Most functions in vrNodePtr are **deprecated**.
   Use the API v2 node types instead:
   For basic node functions, use vrdNode.
   For transform functions, use vrdTransformNode.
   For light functions, use vrdBaseLightNode, vrdPointLightNode, etc.

   Example::

       # Example usage of vrNodePtr
       node = findNode("Group")
       node.setName("ExampleNode")
       node.setTranslation(1.0, 2.0, 3.0)
       print(node.getName())
       print(node.getTranslation())

   Note: This module contains global functions which are mapped to the global namespace. They can be used without creating an instance of the class.

.. method:: createLight(type)

    **Deprecated**. Use API v2 vrLightService.createLight(name, type) instead.

    Creates a light node with the given light type and adds it to the root node of the scenegraph.

    Supported types are: UDirectionalLight, USpotLight, UPointLight, UDiskLight, URectangularLight, USphericalLight, URayLight.

    :param type: The type of the light.
    :type type: string

.. method:: setLocalTranslation(x, y, z)

    Same as setTranslation(x, y, z). Sets the translation of a transform node.

WARNING:
        This legacy function sets the node translation directly, not a translation along rotated local axes,
        to maintain backward compatibility with existing scripts.
        Use vrdTransformNode.setLocalTranslation
        and vrdTransformNode.addLocalTranslation
        in API v2 to change translation along local axes (oriented by the node's rotation and rotation orientation).

    :param x: The x translation.
    :type x: float (32bit)
    :param y: The y translation.
    :type y: float (32bit)
    :param z: The z translation.
    :type z: float (32bit)

.. method:: setTransformMatrix(matrix, transposed)

    Sets the matrix of a matrix transform node.

    Note that standard group transform nodes will recalculate their matrix based on their attributes and therefore the matrix will be lost on every update.

    :param matrix: The 4 x 4 matrix consisting of 16 floats.
    :type matrix: list of floats (32bit)
    :param transposed: Transposed/not transposed.
    :type transposed: bool
