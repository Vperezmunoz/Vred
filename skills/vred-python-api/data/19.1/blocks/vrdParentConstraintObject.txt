-------------------------
vrdParentConstraintObject
-------------------------

.. py:class:: vrdParentConstraintObject

(Inherits vrdConstrainedObject)

This constraint object represents constrained nodes in parent constraints (    vrdParentConstraintNode). It defines how target node transformations control the constrained node as if the constrained node were a child of the targets. To obtain this object, see vrdConstraintNode::getConstrainedObject(vrdNode).
