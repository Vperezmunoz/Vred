-----------------
vrdSceneplateNode
-----------------

.. py:class:: vrdSceneplateNode

(Inherits vrdNode)

Base class for all scene plate types.

Holds all properties for front and back plates. Allow changes and queries. Query methods have get suffix, change methods have set suffix.
